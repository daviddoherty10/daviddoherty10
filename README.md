# Hi, I'm David Doherty

I build web applications and write C and Java. I'm also interested in systems and embedded programming.

## Projects

### [Restringing.ie](https://github.com/daviddoherty10/Restringing.ie)

I'm building a marketplace for racket restringing in Ireland using Go, React, TypeScript and PostgreSQL. Players can find a stringer and track their booking, while stringers manage their services, stock and orders.

Bookings and stock reservations are saved in one database transaction. Prices are stored in integer cents, and the frontend uses types generated from an OpenAPI contract.

The marketplace is currently a preview. The repository has a local demo with fictional accounts and sample data if you'd like to try it.

### [Microprocessor 2048](https://github.com/daviddoherty10/Microprocessor-2048)

An embedded version of 2048, with game logic, display updates and input handling running on a microprocessor.
